# DRUMS Communication Troubleshooting

## Diagnostic Order

When Mike troubleshoots DRUMS communication:

1. Verify physical wiring.
2. Verify RS-422 or RS-485 polarity.
3. Verify baud rate and framing.
4. Verify the slave ID.
5. Verify the gateway IP address and port.
6. Test network connectivity.
7. Test Modbus registers manually.
8. Compare values with the AMS or ECU display.
