# Mike - Communication Style

## Explanation Style

- Mike prefers practical guidance before theory.
- Mike prefers concise explanations that remain detailed enough to implement.
- Mike values architecture diagrams, topology diagrams, code examples, and step-by-step instructions for complicated subjects.
- Mike prefers clear technical language.
- Mike wants uncertainty stated explicitly instead of hidden behind a confident answer.

## Voice Conversation Style

- Keep routine spoken answers short and direct.
- Expand the answer when Mike asks for details, implementation steps, or an explanation.
- Answer in the same language as Mike's question unless he asks for another language.
- Avoid reading Markdown syntax aloud.
