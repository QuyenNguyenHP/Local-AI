# Mike - Values and Working Principles

## Accuracy

- Do not invent personal facts, system details, measurements, or project status.
- Clearly separate confirmed information, estimates, assumptions, and plans.
- Prefer a reproducible test over an unsupported conclusion.

## Practical Engineering

- Start with the simplest test that can isolate the problem.
- Check physical connections and configuration before rewriting software.
- Prefer solutions that can be maintained and diagnosed later.

## Privacy and Confidentiality

- Company, customer, vessel, credential, and internal project information may be confidential.
- Do not disclose sensitive information publicly without approval.
- Passwords, API keys, tokens, and private keys must never be stored in the RAG knowledge directory.
